### Featured Projects

- **[`ChemFlow.NET`](https://github.com/yancsalmeida/ChemFlow.NET)** — Modular steady-state chemical process and thermodynamic simulation engine built with **C# 12 / .NET 8** and **Clean Architecture**. Implements Antoine vapor pressure correlations, Raoult's Law VLE, a safeguarded Newton-Raphson **Rachford-Rice** isothermal flash solver, unit operations (`Mixer`, `HeaterCooler`, `FlashDrum`, `ConversionReactor`), **Kahn's topological sort** for DAG flowsheet execution, **ASP.NET Core Minimal API** endpoints, **SQLite (`ADO.NET`)** persistence, interactive Web Studio dashboard, and automated **`xUnit`** tests.
- **[`ReactorCore.C`](https://github.com/yancsalmeida/ReactorCore.C)** — High-performance non-linear chemical reactor dynamic simulation engine and ODE solver built in **C11 (`gcc`)** with zero external dependencies. Features cache-friendly workspace pre-allocation (zero heap allocation in numerical loops), classical **4th-Order Runge-Kutta (RK4)** integration via **C function pointers**, non-linear **Arrhenius** reaction kinetics, jacket heat-transfer dynamics, thermal runaway detection, and automated unit tests verifying $O(\Delta t^4)$ convergence.
- **[`ProcessTwin.Py`](https://github.com/yancsalmeida/ProcessTwin.Py)** — Real-time industrial process Digital Twin and SCADA telemetry engine built with **Python 3.12**, **FastAPI**, **Asyncio**, **Pydantic v2**, and **aiosqlite**. Runs non-blocking discrete mass/energy balances, emulates sensor noise ($\mathcal{N}(0, \sigma^2)$) on 4–20 mA transmitters, evaluates **Safety Instrumented System (SIS / IEC 61511)** emergency interlocks, streams 5 Hz live telemetry over **WebSockets**, and features an interactive dark-mode SCADA dashboard with SVG instrumentation and Canvas strip charts.
- **[`cs-fundamentals`](https://github.com/yancsalmeida/cs-fundamentals)** — Systems programming and algorithmic modeling laboratories in **C11 (`gcc`)** and **Python 3** on Linux `x86_64`, covering stack/heap virtual memory layout, pointer arithmetic, and discrete process telemetry analysis.
