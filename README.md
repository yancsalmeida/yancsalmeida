### Featured Projects

- **[`ChemFlow.NET`](https://github.com/yancsalmeida/ChemFlow.NET)** — Modular steady-state chemical process and thermodynamic simulation engine built with **C# 12 / .NET 8** and **Clean Architecture**. Implements Antoine vapor pressure correlations, Raoult's Law VLE, a safeguarded Newton-Raphson **Rachford-Rice** isothermal flash solver, unit operations (`Mixer`, `HeaterCooler`, `FlashDrum`, `ConversionReactor`), **Kahn's topological sort** for DAG flowsheet execution, **ASP.NET Core Minimal API** endpoints, **SQLite (`ADO.NET`)** persistence, and automated **`xUnit`** tests.
- **[`cs-fundamentals`](https://github.com/yancsalmeida/cs-fundamentals)** — Systems programming and algorithmic modeling laboratories in **C11 (`gcc`)** and **Python 3** on Linux `x86_64`, covering stack/heap virtual memory layout, pointer arithmetic, and discrete process telemetry analysis.
